> **This is the Vue prototype of the Train Handler client.** It was developed to April 2025 and is
> kept for its history; it is not being changed.
>
> The current consoles are in **`FDTConsole`** — one TypeScript/React codebase with role-based
> apps for the data station operator, the data controller, the train handler's user and the data
> subject, built against the same contracts the components serve. The reasoning is recorded as D3
> in the reference implementation's open questions. It is not yet public.
>
> Start at **[FAIRDataTrain](https://github.com/FAIRDataTeam/FAIRDataTrain)** for what the
> ecosystem is and which components are current.
