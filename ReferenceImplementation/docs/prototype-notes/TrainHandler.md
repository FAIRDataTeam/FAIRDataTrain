> **This repository is the umbrella for the Train Handler prototype** — it carries
> [`TrainHandler-server`](https://github.com/FAIRDataTeam/TrainHandler-server) and
> [`TrainHandler-client`](https://github.com/FAIRDataTeam/TrainHandler-client) as submodules and
> holds no code of its own. It was last changed in February 2023 and is kept for its history.
>
> The current reference implementation of the Train Handler is **`FAIRDataTrainHandler`** (Python
> 3.12), which brings the run model, itinerary orchestration and the handler API into one
> component — the server, the orchestrator and the console are no longer separate products. The
> reasoning is recorded as D1 in the reference implementation's open questions. It is not yet
> public.
>
> Start at **[FAIRDataTrain](https://github.com/FAIRDataTeam/FAIRDataTrain)** for what the
> ecosystem is and which components are current.
