> **This is the Java prototype of the FAIR Data Station.** It was developed to May 2025 and is
> kept for its history; it is not being changed.
>
> The current reference implementation of a Data Station is **`FAIRDataStation-py`** (Python 3.12
> / FastAPI), which is a new implementation rather than a port — it is built against the FAIR Data
> Train contracts (`fdt-commons`, `FDT-O`) and implements the visit protocol, the three policy
> checkpoints and ODRL negotiation on arrival. The reasoning is recorded as ADR-001 and ADR-005.
> It is not yet public.
>
> Start at **[FAIRDataTrain](https://github.com/FAIRDataTeam/FAIRDataTrain)** for what the
> ecosystem is and which components are current.
