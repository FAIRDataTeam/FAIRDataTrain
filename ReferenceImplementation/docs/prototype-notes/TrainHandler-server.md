> **This is the Java / Spring Boot prototype of the Train Handler server.** It was last changed in
> March 2023 and is kept for its history; it is not being changed.
>
> The current reference implementation is **`FAIRDataTrainHandler`** (Python 3.12), which holds
> the run model, itinerary orchestration and the handler API in one component. It is a new
> implementation against the FAIR Data Train contracts rather than a port, and it is not yet
> public. The reasoning is recorded as D1 in the reference implementation's open questions.
>
> Start at **[FAIRDataTrain](https://github.com/FAIRDataTeam/FAIRDataTrain)** for what the
> ecosystem is and which components are current.
